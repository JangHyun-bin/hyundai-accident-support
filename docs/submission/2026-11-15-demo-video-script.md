# 시연 영상 대본과 촬영 목록

목표 길이는 약 4분 45초다. 3~5분은 작업상 목표이며 공식 제한이 아니다. 영상 하나에 문제와 차량 가치, 대표 흐름, 긴급 분기, 기록 보류, 위험 후 복귀, 현재 범위와 다음 범위를 담는다.

## 촬영 원칙

- **화면.** 차량은 공식 Pleos Connect Emulator v2.1.0 (API 34, arm64, 2560×1440) 전체 화면을 녹화한다. 앱은 앱 창(1682×1210)에만 그려지므로 편집에서 앱 창을 확대해도 된다. 휴대폰은 Android 실기기 화면을 미러링해 녹화한다.
- **빌드.** 제출 APK는 서버 없이 동작하는 차량 단독 빌드(`release.sh … standalone`)이며 휴대폰 연결 화면이 없다. 휴대폰 이어받기 장면(7, 8, 10, 13b)은 서버 주소를 넣어 빌드한 연결 시연 APK로 찍는다. 서버는 개발 장비에서 실행하고 Cloudflare 터널의 HTTPS 주소로 연다. 이 장면에는 화면 상단에 `시연 환경 연결 · 제출 APK에는 포함되지 않음` 자막을 계속 띄운다. 나머지 장면은 제출 APK와 같은 화면이다.
- **마이크.** Pleos 에뮬레이터는 기본 설정에서 호스트 마이크를 넘기지 않아 녹음이 0:00으로 저장된다. 차 안 녹음을 보여 주려면 에뮬레이터의 마이크 입력을 켠 상태에서 찍고, 녹음된 길이가 0:00이 아닌지 확인한다. 켤 수 없으면 차 안 기록은 직접 입력으로 찍는다.
- **시연 입력.** 에어백 신호, 새 위험, 보험사 전송 결과처럼 에뮬레이터에서 만들 수 없는 입력은 앱 창의 `시연` 조작으로 넣고, 화면 하단에 `시연 입력` 자막을 붙인다.
- **음성.** 앱 안내 음성이 나오는 구간에서는 내레이션을 멈춘다. 표의 "앱 음성" 칸은 그 구간에 앱이 재생하는 문장이다. 내레이션은 David 톤으로 낮고 고르게, 한 문장씩 끊어 읽는다. 과장하거나 감탄하지 않는다.
- **개인정보.** 휴대폰 알림, 계정 이름, 연락처, 실제 위치를 화면에 띄우지 않는다. 실제 119에 발신하지 않는다. 전화 앱이 열리면 통화 버튼을 누르지 않고 닫는다.
- **촬영 순서.** 기록 보류와 위험 후 복귀는 기록 단계에서 찍어야 하므로 대표 흐름 촬영 중 별도 테이크로 찍고, 편집에서 아래 순서로 배치한다.

## 편집 체크리스트

- [ ] 앱 음성과 내레이션이 겹치지 않는다.
- [ ] `시연 입력`, `보험사 전송 결과는 시연 입력`, `실제 발신하지 않음` 자막이 해당 장면에 있다.
- [ ] 휴대폰 이어받기 장면(7, 8, 10, 13b)에 `시연 환경 연결 · 제출 APK에는 포함되지 않음` 자막이 처음부터 끝까지 보인다.
- [ ] 터널 주소, QR 안의 연결 주소가 읽히지 않도록 자막이나 흐림으로 가린다.
- [ ] 휴대폰 화면에 알림, 계정, 연락처, 실제 위치가 보이지 않는다.
- [ ] 차량 화면의 글자가 잘리지 않는다.
- [ ] 전체를 처음부터 끝까지 재생해 검은 화면, 소리 누락, 소리 크기를 사람이 확인한다.
